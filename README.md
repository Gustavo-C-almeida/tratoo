# tratoo
Marketplace de prestação de serviços digitais (design, marketing, social media, edição de vídeo, dados/BI, tradução, desenvolvimento de software, consultoria e mais) que conecta clientes e profissionais de qualquer especialidade. Construído em .NET 8 com Minimal APIs, Clean Architecture e Feature Folders. Contratos digitais, pagamento protegido (escrow) via Asaas/PIX, identidade verificada, busca semântica com OpenAI Embeddings + pgvector, MFA, LGPD, AES-256, JWT HttpOnly, SQL Server, PostgreSQL e frontend HTML/CSS/JS vanilla.
